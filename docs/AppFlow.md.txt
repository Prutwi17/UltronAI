# 3. Order Tracking

User:
"Where is my order?"

↓

Intent:

ORDER_TRACKING

↓

Check Order ID

↓

If missing:

Ask user for Order ID

↓

Order ID received

↓

Call Order API

↓

Retrieve status

↓

Generate response

↓

Send response

# 4. Order Cancellation

↓

↓

# 8. AI Failure Flow

Message
↓
NLP
↓
Confidence score

If confidence >= threshold:

Execute intent

If confidence < threshold:

Fallback response

↓

Try clarification

↓

If repeated failure:

Human escalation
